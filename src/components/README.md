# UI Components

This folder contains the React components that make up the user interface.

- `CalendarView.tsx`: Displays the monthly overview and list view of upcoming services.
- `LiveTransposer.tsx`: Helper component to display chord transpose and media guide within the app interface.
- `ScheduleManager.tsx`: Organizes the creation and editing of service events.
- `SetlistBuilder.tsx`: A drag-and-drop interactive builder to arrange songs for a specific service.
- `SongLibrary.tsx`: Component managing the inventory of available songs, including CRUD operations.
- `ThemeProvider.tsx` / `ThemeToggle.tsx`: Utilities to handle application dark/light mode switching.
