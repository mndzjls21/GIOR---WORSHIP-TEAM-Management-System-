# Source Code Directory

This directory contains the main application code for the Worship Setlist Builder.

- `components/` - React components including views for the library, schedule, and setlists.
- `lib/` - Shared utilities and integration files like Firebase setup configuration.
- `types.ts` - Centralized TypeScript interfaces and data models.
- `App.tsx` - The main application shell and root component.
- `main.tsx` - Vite React entry point.
- `index.css` - Global stylesheet with Tailwind CSS imports.
